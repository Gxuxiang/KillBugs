# 游戏背景设计

在一场世界大战之后，地球上的节肢动物产生了变异进化，它们开始爆炸式繁殖，整个生物圈打破平衡，地球变得不再适宜人类生存，人类全部迁移到近地轨道空间站生存。空间站物质匮乏，随着太空电梯的建造，空间站时代前往地球杀虫获取资源成为时下最热门的工作之一。

# 游戏机制设计

我想的是每过几波虫潮，就在地图上随机出现一个撤离点（一小块区域）（UI上会有倒计时显示比如 3波虫潮后撤离点出现），玩家到达区域后开启撤离计时，计时期间（出现大规模虫潮），计时结束在撤离区域的玩家成功撤离。撤离点出现时会在屏幕边缘有方向指示。
虫子会随机掉落物品（比如药包，材料啥的）
场景我想做成那种生成式的迷宫，有各个房间那种，玩家打开房间可以在里面探索，可能会遭遇虫子，也可能拿到珍贵材料
材料是玩家主要搜的东西，用于局外合成更加强大的枪械和装备，也可以在商店卖出金币兑换物品

玩家死亡时 会有个救助范围的圈，队友进入这个圈就开始救助计时，计时结束（玩家复活，回复一半的血量），如果队友离开这个圈 再次进入就是重新计时
当所有玩家死亡时游戏结束，装备所有物品包括捡到的物品都会掉落，只有打虫子赚的金币不掉落

# 已定的设计决策

> 2026-10-04 讨论确定。这些是**约束**，实现时不要再重新发明一遍。

## 撤离

- 只有**全员存活且都在撤离区域内**才开始计时。倒地的队友必须先被救起来 ——
  这条让救援从"锦上添花"变成撤离的必经环节。
- 有人离开区域时计时**暂停**，不重置。（4 个人很难保持完美同步，重置会变成互相甩锅。）
- 计时期间刷一波大规模虫潮。
- 撤离点每过几波随机出现一次；出现前 UI 有预告（"X 波后出现"），出现后屏幕边缘有方向指示。
- **有人撤离成功 = 这一局结束**，全队一起结算。
- **一局结束 = 世界立刻停下来**：清掉场上所有虫子，所有人的移动/瞄准/开火全部锁住，
  然后结算界面停留 N 秒回大厅。团灭走同一条路（两个结局经由同一个 `EndRun`）。

## 撤离的两个钟（2026-10-05 定）

撤离点本身有**开启时间**，这段时间里它是敞开的。两个钟**互斥**，任何时刻只有一个在走：

| 钟 | 什么时候走 | 走完会怎样 |
|---|---|---|
| **开启时间** | 「不是全员存活且都在圈内」时 | **撤离失败**：撤离点关闭，**这一局继续**，过 N 波再出现 |
| **撤离计时** | 全员存活且都在圈里时（同时开启时间**冻结**） | **撤离成功**：这一局结束 |

- 玩家没在开启时间内到达 → 直接关闭，撤离失败。
- 中途有人离开圈 → 撤离计时**暂停**（保留进度），开启时间**继续**。
- 倒地的人不算"在圈内"，所以不救起队友就撤不走。

**为什么需要开启时间**：「有人离开则暂停、不重置」这条规则，在没有截止时间的前提下
成本是零——队伍可以一直在圈外耗着，想什么时候进去就什么时候进去。开启时间就是那个
一直在走的东西，它给了「不在圈里」一个价格。UI 上因此有两个数字：一个总倒计时 + 一个读条。

**大规模虫潮在「玩家开启撤离」那一刻来**，不是撤离点一出现就来（2026-10-05 实测后改的）：

- 撤离点出现 → 什么都不发生，跑过去的那段路是正常的 Explore。
- 全员进圈、读条开始 → 立刻一波（`ExtractionOpeningBurst`）+ 读条期间维持 `ExtractionSpawnRate`。
- 有人出圈 → 虫潮停，回到 Explore 的涓涓细流；窗口恢复倒计时。
- 每个撤离点**只给一次**这波虫潮（第一次全员进圈时），反复进出不会重复触发。

**为什么**：一开始把虫潮挂在"撤离点存在"上，实测两局都撑不到撤离点——撤离点按设计刷在
离队伍最远处，再叠上 22/秒的虫潮，**最难的变成了"走过去"**，而不是"守住"。而设计要的是守住。

## 搜

- 虫子随机掉落（药包、材料）。**已实现 2026-10-05**：走过去自动拾取；药包即时回血，
  **满血时不捡**（留在地上）；材料带在身上。
- 迷宫的房间里能找到珍贵材料。（**未实现**，要等阶段 4 的生成式迷宫）
- 材料是主要搜的东西，两个去处：局外合成枪械/装备、卖给商店换金币。
  **已实现一半**：撤离成功才带得回家（进仓库），团灭丢光；商店和合成还没做。

## 风险

- 团灭 = **装备和所有携带物品全部掉光，包括从仓库带进去的装备**（塔科夫式，赌注拉满）。
- **只有击杀赚的金币不掉。** 金币因此必须跨局持久化，且只用于局外商店。
- 存档里至少要有：**仓库（材料/装备）+ 金币**。

## 救援

- 倒地出现救助圈，队友进圈开始读条。
- 读完 → 复活，回复**一半**血量。
- 队友**离开圈再进 = 重新计时**（注意这条和撤离的"暂停"不同，是有意的）。

## 局外

- 仓库 + 配装：进局前选好装备带进去。
- 商店：卖材料换金币，金币买物品。
- 合成：材料 → 更强的枪械/装备。

## 阶段 4 的前置警告（重要）

虫群是**自定义转向 + 空间哈希分离**，完全不走 NavMesh —— 这恰恰是它 600 只能跑得动的原因。
地图一旦从平板变成有墙的房间，**虫子会直接撞墙、卡在墙角和门框上**。
给 600 只虫子做 NavMesh 寻路基本等于放弃现在的性能预算。

可行解是**流场（flow field）**：在网格上算"到玩家"的方向场，虫子查表转向，
开门关门时局部重算即可。这和现有的空间哈希是同一路子。
**这是一整块独立工程，不要和地图生成捆在一起做。**
